# 🚗 ROS2 Autonomous Driving Simulation

ROS2 · Gazebo 기반 자율주행 차량 시뮬레이션 프로젝트입니다.

---

## 📌 프로젝트 소개

Gazebo 시뮬레이션 환경에서 자율주행 차량을 제어하는 프로젝트입니다.

OpenCV 기반 차선 인식 및 정지선 감지 기능을 구현하였으며,
장애물 및 보행자를 감지하여 충돌 없이 주행하도록 설계했습니다.

ROS2 노드 간 토픽 통신을 활용하여 차량 제어와 센서 데이터를 처리했습니다.

---

## 🛠 Tech Stack

### Simulation
- ROS2
- Gazebo

### Language
- Python

### Vision
- OpenCV

### Environment
- Ubuntu Linux

---

## ✨ 주요 기능

- 차선 인식 및 주행
- 정지선 감지 후 정차
- 장애물 감지 및 회피
- 보행자 감지
- Gazebo 기반 주행 환경 구성
- ROS2 Topic 기반 차량 제어
- 실시간 차량 상태 확인

---

## 👨‍💻 담당 역할

- Gazebo 기반 장애물 환경 구현
- 육면체 장애물 생성 및 이동 로직 구현
- ROS2 기반 장애물 제어 기능 구현
- 시뮬레이션 환경 테스트 및 디버깅
